# Sidebar.py - Brief Documentation

**Path**: `orchetrix/UI/Sidebar.py`
**Lines**: ~400

## Purpose
Left sidebar with cluster list and navigation

## Components
- **Cluster Section**: List of available clusters with status
- **Pinned Resources**: Quick access to pinned items
- **Navigation Menu**: Page categories and pages

## Features
- Cluster selection and switching
- Connect/disconnect clusters
- Pin/unpin resources
- Collapsible menu sections
- Search navigation

## Signals
- `cluster_selected` - User selected a cluster
- `page_selected` - User selected a page
- `pin_clicked` - User clicked pinned resource
