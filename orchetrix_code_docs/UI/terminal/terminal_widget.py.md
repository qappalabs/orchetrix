## Purpose
Terminal widget for interactive shell

## Features
- Command input/output display
- ANSI color support
- Command history (up/down arrows)
- Copy/paste support
- Auto-scroll

## Signals
- `commandEntered` - User entered command

## Used By
TerminalPanel (regular terminal tabs)
