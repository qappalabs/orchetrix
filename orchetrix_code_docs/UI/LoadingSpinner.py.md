# LoadingSpinner.py - Brief Documentation

**Path**: `orchetrix/UI/LoadingSpinner.py`
**Lines**: ~80

## Purpose
Animated loading spinner widget

## Features
- Rotating spinner animation
- Multiple sizes (small, medium, large)
- Overlay mode
- Show/hide methods

## Usage
```python
spinner = LoadingSpinner(self)
spinner.start()  # Start animation
spinner.stop()   # Stop animation
```

## Used By
All resource pages during data loading
