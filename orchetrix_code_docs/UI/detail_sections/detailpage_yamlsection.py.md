## Purpose
YAML tab with syntax highlighting and editing

## Features
- Syntax-highlighted YAML display
- Edit YAML in place
- Apply button to update resource
- YAML validation before applying
- Diff view for changes

## Actions
- **Edit**: Enable editing mode
- **Apply**: Update resource in cluster
- **Cancel**: Discard changes
- **Download**: Save YAML to file

Extends BaseDetailSection
