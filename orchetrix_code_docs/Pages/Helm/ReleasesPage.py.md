- Release Name
- Namespace
- Chart
- Version
- Status (deployed/failed/pending)

## Key Features
- Upgrade releases
- Rollback to previous revision
- Uninstall releases
- View release history
- View release values
- View release notes

## Actions
- Upgrade → Update with new values
- Rollback → Revert to revision
- Delete → Uninstall release
