# ChartsPage.py - Brief Documentation

**Path**: `orchetrix/Pages/Helm/ChartsPage.py`
**Lines**: ~400

## Purpose
Browse and install Helm charts

## Features
- List available Helm charts from repositories
- Search charts
- View chart details (README, values.yaml)
- Install charts with custom values
- Select chart version

## UI Components
- Chart list with search
- Chart detail panel
- Values editor
- Install button

## Actions
- Install chart → Creates Helm release
- View README
- View default values.yaml
